# Mobile Sales Data Analysis

## Project Overview
This project analyzes mobile phone sales data using Python to uncover valuable business insights related to revenue generation, product performance, customer purchasing behavior, and regional sales trends.

The analysis was performed using data cleaning, aggregation, exploratory data analysis (EDA), and data visualization techniques in Jupyter Notebook.

---

## Objectives
The main objectives of this project were to:

- Analyze overall sales performance
- Identify top-performing mobile brands and products
- Determine which regions generated the highest revenue
- Analyze customer purchasing behavior
- Visualize important business KPIs using charts and graphs

---

## Tools & Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## Dataset
The dataset contains mobile sales transaction data including:

- Product Name
- Brand
- Region
- Quantity Sold
- Revenue
- Customer Information

---

## Key Analysis Performed

### Data Cleaning
- Checked for missing values
- Removed inconsistencies
- Corrected data formatting issues

### Exploratory Data Analysis (EDA)
- Total revenue analysis
- Sales by region
- Top-selling products
- Brand performance comparison
- Customer purchasing trends

### Data Visualization
Visualizations created include:
- Revenue by brand
- Top-selling products
- Regional sales comparison
- Heatmaps for regional product performance
- Revenue distribution charts

---

## Key Insights
- Certain brands generated significantly higher revenue than others
- The Central region recorded strong sales performance
- Product popularity varied across regions
- Customer purchasing patterns revealed high-demand products
